# Dota 2 Match Coach

[English](README.md) | [Русский](README.ru.md)

Скилл для агента: разбирает матч Dota 2 на текущем патче, как тренер. Он находит одну главную проблему, показывает момент или цифру, которые её подтверждают, даёт помеченный совет и одно упражнение на следующую игру. Встроенный рантайм забирает матч из OpenDota (и, если есть ключ, из STRATZ), сверяет точный сабпатч с Valve и пишет нормализованный артефакт с фактами. Цифры в разборе берутся только из этого артефакта.

Поддерживается только последний точный сабпатч. Матчи со старых патчей отклоняются, и поддержки их не будет.

## Что используется

Без ключей, из разобранного матча OpenDota:

- каждая смерть игрока: время, кто убил (герой, башня, крипы…), сколько был мёртв, сколько золота потерял, была ли это записанная драка и кто в ней участвовал с каждой стороны; смерти до горна тоже учитываются;
- лайн, союзники и соперники по линии, ластхиты, денаи, золото, опыт и нетворс всех игроков на 10:00;
- все десять игроков: K/D/A, фарм, урон, итоговые предметы и тайминги всех крупных покупок;
- перцентили OpenDota по показателям игрока среди игроков на том же герое;
- экономика команд, объекты, варды, байбеки, порядок прокачки, фазы, механики текущего патча из datafeed Valve;
- предупреждения про Turbo и другие нестандартные режимы (нормы обычных игр к ним не применяются) и про ливеров.

С `STRATZ_API_KEY` добавляются позиции всех героев, использования предметов и способностей игрока, ТП, полный контекст смертей (кто был рядом, умер ли в одиночку, были ли размены), итог лайна по STRATZ и средние по выборке того же героя, позиции и ранга.

## Требования

- Node.js 18+ (за HTTP-прокси нужен 22.21+ или 24.5+); `npm install` не нужен;
- доступ в сеть к OpenDota и Valve (и к STRATZ, если задан ключ);
- PowerShell на Windows или POSIX `sh` на macOS/Linux для обёрток.

## Установка

Через [Vercel Skills](https://github.com/vercel-labs/skills):

```sh
npx skills add atlonis/dota2-coach-skill --skill dota2-match-coach --global --copy
```

Потом в новой сессии агента:

```text
Используй $dota2-match-coach: разбери мою последнюю игру, аккаунт 56386500.
Используй $dota2-match-coach: разбери https://www.dotabuff.com/matches/9048031561 за игрока на Skywrath Mage.
```

Матч задаётся ID или ссылкой Dotabuff/OpenDota/STRATZ. Если ID нет, скилл покажет последние матчи игрока. Игрока можно указать friend ID, Steam64, ссылкой на профиль, точным английским именем героя или слотом 0–9. Герой и слот работают и для игроков со скрытым аккаунтом.

Обновить или удалить:

```sh
npx skills update dota2-match-coach --global --yes
npx skills remove dota2-match-coach --global
```

## Ключи

Оба необязательны. Задавайте их в окружении агента или в менеджере секретов, но не в запросах, командах, файлах проекта и Git.

- `STRATZ_API_KEY` даёт playback STRATZ и средние по выборке (см. выше).
- `OPENDOTA_API_KEY` поднимает лимит запросов OpenDota и ускоряет ожидание разбора.

## Запуск рантайма напрямую

```sh
cd dota2-match-coach
node scripts/recent-matches.mjs --account-id 56386500
node scripts/analyze-match.mjs --match-id 9048031561 --account-id 56386500 --output-dir ./output
node scripts/check-review.mjs --artifact ./output/9048031561.json --review draft.md
```

Разобранный матч обрабатывается секунд за 10. Неразобранный ждёт разбора OpenDota: обычно 15–60 секунд, максимум две минуты. Коды выхода, ошибки и устройство артефакта описаны в [runtime](dota2-match-coach/references/runtime.md).

## Разборы

Полный (по умолчанию), короткий или по теме (лайн, смерти, предметы, фарм, драфт, прогресс). У фактов есть таймкоды. Гипотеза требует двух и более независимых фактов и помечается. Совет помечается «Совет тренера». У упражнения есть самопроверка, которую игрок посчитает без реплея. Разбор пишется на языке пользователя, по-русски словами игроков. Образцы лежат в [examples](dota2-match-coach/references/examples.md).

Личный прогресс сравнивает матч с ранее сохранёнными артефактами того же аккаунта, героя, позиции, режима и патча (`--history-dir`), см. [progress](dota2-match-coach/references/progress.md).

## Проверка

```sh
node --test test/runtime/*.test.mjs dota2-match-coach/scripts/test/*.test.mjs
```

Тесты работают без сети. В них есть реальные ответы OpenDota по матчам 7.41f (`test/fixtures/opendota`, ID аккаунтов чужих игроков заменены), они гоняются в CI на Linux и Windows. Сам ответ коуча проверяется [офлайн-сценариями для агента](test/coaching/README.md) и [бенчмарком на реальных матчах](test/benchmark/README.md), а `check-review.mjs` сверяет черновик разбора с артефактом.

**Живой smoke-тест (по желанию).** Возьмите свежий матч на текущем патче, задайте только в текущей оболочке `DOTA2_COACH_LIVE_MATCH_ID` и `DOTA2_COACH_LIVE_ACCOUNT_ID` (или `DOTA2_COACH_LIVE_HERO`) и запустите из корня скилла `node --test dota2-match-coach/scripts/test/live-smoke.test.mjs`. Без переменных тест пропускается. После прогона уберите их и не коммитьте значения.

## Структура репозитория

```text
dota2-match-coach/          устанавливаемый скилл
  SKILL.md                 порядок работы агента
  references/              шаблон разбора, политика источников, смерти, выбор главного, справка тренера, примеры, runtime, прогресс
  scripts/                 рантайм, последние матчи, проверка разбора, обёртки, тесты скилла
test/runtime/              офлайн-тесты, включая тесты на реальных ответах
test/fixtures/opendota/    реальные ответы OpenDota для тестов
test/coaching/             синтетическая проверка ответа коуча
test/benchmark/            протокол и результаты бенчмарка на реальных матчах
research/coaching-videos/  заметки по 50 видео тренеров и их синтез
ROADMAP.md, RESEARCH.md    план развития и исследования
```

## Источники данных и атрибуция

Данные матчей берутся из [OpenDota](https://www.opendota.com), а при заданном ключе ещё и из [STRATZ](https://stratz.com). Даты патчей и механики текущего патча берутся из публичного datafeed Dota 2 от Valve. Проект не связан с Valve, OpenDota и STRATZ и не одобрен ими. Dota 2 — товарный знак Valve Corporation. Соблюдайте условия и лимиты каждого сервиса.
